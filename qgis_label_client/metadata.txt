about=Connects QGIS to a labeling platform that serves OGC API - Features (Parts 1, 2 and 4).
    QGIS's native provider does all vector reading and editing, so this plugin only covers what
    QGIS cannot do on its own:
    .
    * signs in with Google in your browser and stores the resulting token in QgsAuthManager,
      so no credential is ever written into a .qgz - and renews that token in the background,
      because it lives about an hour and an editing session does not;
    * refreshes short-lived signed object-storage URLs and re-points raster layers at them,
      which a project file cannot do because the URLs expire;
    * loads collections and the label class vocabulary from the backend, so forms and styling
      cannot drift from the server's class registry;
    * an as-of-date control on valid time, sent as the OGC datetime parameter or as a CQL2
      filter;
    * a historical view on transaction time - a read-only layer showing the labels as the team
      believed them at a chosen instant, including ones deleted since. Transaction time has no
      OGC parameter, so the instant rides on a per-layer request header, which is also what
      makes QGIS grey the pencil out on that layer by itself;
    * QA: a label's edit history, and a check for labels drawn outside any declared
      exhaustive survey extent;
    * a one-time bootstrap that publishes the vector layers already open in the project as
      the founding dataset, previewing the class mapping, the damaged names and the missing
      survey coverage before anything is sent.
    .
    Licensed under GPL v2 or later, as required for QGIS plugins. No credentials, imagery or
    deployment hostnames are distributed with this plugin - the backend URL is a user setting.
